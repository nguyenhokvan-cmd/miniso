# MINISO Final Project

## Features
- Home page with Header / Body / Footer
- Product introduction and product detail
- Product search and category filter
- Responsive design for desktop/tablet/mobile
- Register / Login using LocalStorage
- Cart using LocalStorage
- Contact form
- Product images are loaded directly from online image URLs
- Organized CSS and JS folders

## Run
Open `index.html` in a browser.

## LocalStorage keys
- `users`
- `currentUser`
- `cart`

This is a student final-course project inspired by the MINISO shopping experience.

## Image URLs
Product cards use online image URLs in `js/products-data.js`, so product images do not need to be stored locally.
